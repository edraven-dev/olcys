# @olcys/collectors

Adaptery źródeł OSINT za portem SourceCollector (Bitcointalk, BitList, ENS, Keybase, GitHub, Farcaster, Nostr, podglądy kanałów Telegram, rejestry publiczne, klient Maigret, wyszukiwarki, Wayback) oraz planer rozwijania wyszukiwania (pivotów).

- **Zależności:** wyłącznie kontrakty `@olcys/core`. Inne pakiety są dostępne przez porty łączone w `apps/worker`.
- **Testy:** `test/*.test.ts`, uruchamiane poleceniem `pnpm vitest run --project @olcys/collectors`.
