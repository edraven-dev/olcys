# @olcys/reporting

Model raportu (fakty źródłowe / wyniki obliczeń / wnioski), renderowanie HTML i PDF/A, eksport do STIX, MISP i CSV.

- **Zależności:** wyłącznie kontrakty `@olcys/core`. Inne pakiety są dostępne przez porty łączone w `apps/worker`.
- **Testy:** `test/*.test.ts`, uruchamiane poleceniem `pnpm vitest run --project @olcys/reporting`.
