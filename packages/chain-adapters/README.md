# @olcys/chain-adapters

Dostawcy danych blockchain za portem ChainProvider (Esplora, Etherscan V2, API Otterscan dla węzłów własnych, TronGrid, Solana RPC); ten sam interfejs dla publicznych API, węzłów utrzymywanych lokalnie i sieci testowych w piaskownicy.

- **Zależności:** wyłącznie kontrakty `@olcys/core`. Inne pakiety są dostępne przez porty łączone w `apps/worker`.
- **Testy:** `test/*.test.ts`, uruchamiane poleceniem `pnpm vitest run --project @olcys/chain-adapters`.
