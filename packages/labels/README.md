# @olcys/labels

Etykiety adresów z informacją o pochodzeniu, klasyfikacja typu adresu (EOA, kontrakt, EIP-7702, Safe) i reguły odrzucania błędnych przypisań A1–A8.

- **Zależności:** wyłącznie kontrakty `@olcys/core`. Inne pakiety są dostępne przez porty łączone w `apps/worker`.
- **Testy:** `test/*.test.ts`, uruchamiane poleceniem `pnpm vitest run --project @olcys/labels`.
