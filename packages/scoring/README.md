# @olcys/scoring

Dwuetapowy Wskaźnik Pewności oparty na ilorazach wiarygodności, z wyjaśnieniem wkładu każdej cechy.

- **Zależności:** wyłącznie kontrakty `@olcys/core`. Inne pakiety są dostępne przez porty łączone w `apps/worker`.
- **Testy:** `test/*.test.ts`, uruchamiane poleceniem `pnpm vitest run --project @olcys/scoring`.
