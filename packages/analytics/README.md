# @olcys/analytics

Wycena w PLN (kursy NBP), wskaźniki aktywności, wymiany i konwersje na stablecoiny, reguły wyjścia do walut tradycyjnych B1–B7 oraz graf przepływu środków.

- **Zależności:** wyłącznie kontrakty `@olcys/core`. Inne pakiety są dostępne przez porty łączone w `apps/worker`.
- **Testy:** `test/*.test.ts`, uruchamiane poleceniem `pnpm vitest run --project @olcys/analytics`.
